# Triage Labels

Use these labels, or the closest equivalent status/label in the configured issue tracker:

| Role | Label |
| --- | --- |
| Needs maintainer evaluation | `needs-triage` |
| Waiting on reporter | `needs-info` |
| Ready for AFK agent | `ready-for-agent` |
| Ready for human implementation | `ready-for-human` |
| Will not be actioned | `wontfix` |
